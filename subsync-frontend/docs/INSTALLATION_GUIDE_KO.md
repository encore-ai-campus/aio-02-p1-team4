# SubSync 설치 가이드

SubSync는 YouTube에서 영어·한국어 자막을 함께 보고, 자막 속 단어를 학습하고, 영상 문맥을 AI Tutor에게 질문할 수 있는 Chrome 확장 프로그램입니다.

이 문서는 일반 사용자 설치와 개발자 모드 설치를 모두 설명합니다.

> **현재 배포 상태 안내**
>
> 현재 저장소의 확장 프로그램은 Manifest V3, 버전 `1.0.0` 기준입니다. Chrome Web Store 주소가 확정되지 않았으므로 아래 Web Store 주소에는 자리표시자가 사용됩니다. 저장소의 개발용 코드가 `http://127.0.0.1:8000/api/v1`을 기본 API 주소로 사용하는 경우, 개발자 모드로 설치해도 해당 백엔드가 실행 중이어야 Tutor·사전·원격 단어 저장 기능이 정상 동작합니다. 공개 배포 전에는 [배포 전 체크리스트](RELEASE_CHECKLIST_KO.md)를 먼저 확인하십시오.

## 1. 설치 전 확인

### 지원 환경

- Google Chrome 최신 버전 또는 Manifest V3를 지원하는 Chrome 환경
- `https://www.youtube.com/watch...` 형식의 YouTube 영상 페이지
- 영어 또는 사용 가능한 자막 트랙이 있는 영상
- 자막·로그인·AI 기능을 사용하는 경우 인터넷 연결

SubSync의 핵심 화면은 Chrome 확장 프로그램 팝업이 아니라 YouTube 영상 페이지 위에 표시됩니다. 설치 후 YouTube 탭을 새로고침해야 화면이 나타납니다.

### 개발용 설치본의 추가 조건

개발자 모드로 설치하는 경우 다음 항목도 필요합니다.

- `manifest.json`이 최상위에 있는 압축 해제 폴더
- 개발용 백엔드가 필요한 기능을 사용하는 경우 실행 중인 SubSync 백엔드
- Google 로그인을 사용하는 경우 운영자가 설정한 Supabase Auth·Google OAuth·확장 프로그램 callback 주소

사용자는 API 키, 비밀번호, Google client secret, Supabase secret key 또는 자막 인증값을 입력하지 않습니다.

## 2. Chrome Web Store에서 설치

Chrome Web Store 등록이 완료된 배포본을 사용하는 일반 사용자는 다음 순서로 설치합니다.

1. Chrome에서 공식 SubSync Chrome Web Store 주소를 엽니다.
   - 현재 문서의 자리표시자: `[SubSync Chrome Web Store URL]`
2. 확장 프로그램 이름과 게시자가 공식 배포본인지 확인합니다.
3. **Chrome에 추가**를 선택합니다.
4. Chrome이 표시하는 권한을 확인한 뒤 설치를 승인합니다.
5. Chrome 오른쪽 상단의 퍼즐 모양 **확장 프로그램** 아이콘을 선택합니다.
6. SubSync 오른쪽의 고정 아이콘을 선택하면 주소 표시줄 옆에서 쉽게 열 수 있습니다.
7. YouTube 영상 페이지를 새로 열거나 이미 열려 있는 YouTube 탭을 새로고침합니다.

YouTube 영상 위에 `SubSync · ON` 퀵바가 표시되면 설치가 완료된 것입니다.

## 3. 개발자 모드로 설치

Chrome Web Store에 등록하기 전 내부 테스트 또는 사내 배포에는 압축 해제된 확장 프로그램 설치를 사용할 수 있습니다.

### 3.1 설치 폴더 준비

1. SubSync 배포 ZIP 파일을 내려받거나 저장소 폴더를 준비합니다.
2. ZIP 파일을 일반 폴더에 압축 해제합니다.
3. 선택할 폴더의 최상위에 `manifest.json`이 있는지 확인합니다.
4. `manifest.json`이 하위 폴더에 있다면 해당 하위 폴더를 Chrome에 선택합니다.

정상적인 폴더 구조의 예시는 다음과 같습니다.

```text
SubSync-release/
├─ manifest.json
├─ popup.html
├─ privacy.html
├─ src/
├─ styles/
└─ assets/
```

### 3.2 Chrome에 불러오기

1. Chrome 주소 표시줄에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드**를 선택합니다.
4. `manifest.json`이 들어 있는 폴더를 선택합니다.
5. 확장 프로그램 목록에 **SubSync** 카드가 표시되는지 확인합니다.
6. 오류가 표시되면 카드의 **오류** 버튼을 열어 파일 경로와 문법 오류를 확인합니다.
7. YouTube 탭이 이미 열려 있었다면 해당 탭을 새로고침합니다.
8. 주소 표시줄 옆 퍼즐 메뉴에서 SubSync를 고정합니다.

> 개발자 모드 설치본은 폴더 위치와 파일이 변경되면 동작하지 않을 수 있습니다. 폴더를 이동하거나 새 버전으로 교체한 뒤에는 `chrome://extensions`에서 해당 확장 프로그램을 다시 로드하십시오.

## 4. 설치 후 최초 실행

1. 자막이 제공되는 YouTube 영상을 엽니다.
2. 영상 페이지가 완전히 로드될 때까지 기다립니다.
3. 영상 위에 `SubSync · ON` 퀵바와 메인 패널이 표시되는지 확인합니다.
4. 패널의 **로그인** 버튼을 선택하면 Google 로그인 흐름을 시작할 수 있습니다.
5. 패널 상단 버튼이 **로그아웃**으로 바뀌면 로그인 세션이 확장 프로그램에 복원된 상태입니다.
6. 기능 사용 방법은 [사용자 가이드](USER_GUIDE_KO.md)를 확인합니다.

## 5. Chrome 권한 안내

| 권한 또는 접근 범위 | 사용 목적 |
| --- | --- |
| `storage` | 테마·폰트·자막 관련 설정, 인증 세션, 로컬 단어 및 시청기록을 확장 프로그램 저장소에 보관합니다. |
| `activeTab` | 현재 YouTube 탭에 SubSync 학습 UI를 표시하고 현재 영상과 상호작용합니다. |
| `webRequest` | YouTube 자막 요청을 관찰하여 현재 영상에 맞는 자막 정보를 처리합니다. |
| `identity` | Google OAuth 로그인 창을 열고 callback을 처리합니다. |
| YouTube 호스트 접근 | YouTube 영상 페이지의 영상·자막·제목·썸네일을 기능에 필요한 범위에서 처리합니다. |
| 백엔드 및 Supabase 호스트 접근 | 인증, Tutor, 사전 및 단어 저장 등 SubSync 서버 기능과 통신합니다. |

SubSync는 외부 서버에서 JavaScript 또는 WebAssembly 코드를 내려받아 실행하지 않습니다. 확장 프로그램에서 실행되는 코드는 설치된 확장 프로그램 패키지에 포함됩니다. 자세한 정보는 확장 프로그램의 [개인정보처리방침](../privacy.html)을 확인하십시오.

## 6. 업데이트

### Chrome Web Store 설치본

Chrome이 게시된 새 버전을 자동으로 업데이트합니다. Chrome에서 즉시 업데이트를 확인하려면 다음과 같이 진행할 수 있습니다.

1. `chrome://extensions`를 엽니다.
2. **개발자 모드**를 켭니다.
3. **업데이트**를 선택합니다.
4. 열려 있는 YouTube 탭을 새로고침합니다.

### 개발자 모드 설치본

1. 새 버전 폴더를 준비합니다.
2. `chrome://extensions`에서 SubSync 카드의 **새로고침** 아이콘을 선택합니다.
3. 폴더를 교체한 경우 새 폴더를 다시 **압축해제된 확장 프로그램을 로드**로 불러옵니다.
4. YouTube 탭을 새로고침합니다.
5. 확장 프로그램 카드에서 버전과 오류 표시를 확인합니다.

Manifest, content script 또는 service worker가 변경된 경우 확장 프로그램을 다시 로드한 뒤 YouTube 탭도 반드시 새로고침하십시오.

## 7. 삭제

1. `chrome://extensions`를 엽니다.
2. SubSync 카드의 **삭제**를 선택합니다.
3. 삭제를 확인합니다.

확장 프로그램 삭제 또는 브라우저 프로필의 저장공간 초기화 시 Chrome 확장 프로그램 저장소에 있던 설정, 로컬 단어 및 로컬 시청기록이 사라질 수 있습니다. 서버에 저장된 데이터의 삭제는 서비스 운영자가 제공하는 삭제 절차를 따르십시오.

## 8. 문제 해결

### 퀵바나 메인 패널이 보이지 않습니다.

1. 현재 주소가 `https://www.youtube.com/watch...`인지 확인합니다.
2. `chrome://extensions`에서 SubSync가 사용 설정되어 있는지 확인합니다.
3. YouTube 탭을 새로고침합니다.
4. 개발자 모드 설치본이면 SubSync 카드의 오류를 확인합니다.
5. 다른 확장 프로그램이 화면을 가리고 있지 않은지 확인합니다.
6. YouTube가 완전히 로드될 때까지 잠시 기다린 뒤 다시 시도합니다.

### 자막이 표시되지 않습니다.

1. 현재 영상에 영어 자막 또는 사용할 자막 트랙이 있는지 확인합니다.
2. YouTube의 자막을 켠 뒤 SubSync의 새로고침 버튼을 선택합니다.
3. `자막 요청이 제한됐습니다 (HTTP 429)`가 표시되면 잠시 기다린 후 다시 시도합니다.
4. 빈 자막 또는 파싱 오류가 표시되면 영상 페이지를 새로고침합니다.
5. 자막 인증값이나 토큰을 입력하라는 안내가 나오면 입력하지 말고 운영자에게 오류 문구를 전달합니다.

### Google 로그인에 실패합니다.

- 확장 프로그램의 Supabase URL과 공개용 publishable/anon key가 올바르게 설정되었는지 운영자에게 확인합니다.
- Google provider가 Supabase에서 활성화되어 있는지 확인합니다.
- Chrome 확장 프로그램 ID에 해당하는 callback 주소가 Supabase Redirect URL에 등록되어 있는지 확인합니다.
- 로그인 창을 닫았다면 다시 **로그인**을 선택합니다.
- 계속 실패하면 오류 문구와 확장 프로그램 버전을 운영자에게 전달합니다.

사용자는 Google client secret이나 Supabase secret key를 확장 프로그램에 직접 입력하지 않습니다.

### AI Tutor가 답변하지 않습니다.

- 로그인 상태인지 확인합니다.
- 네트워크 연결을 확인합니다.
- 개발용 설치본이면 SubSync 백엔드가 실행 중인지 확인합니다.
- 질문을 짧고 명확하게 다시 입력합니다.
- AI provider의 일시적인 장애, 사용량 제한 또는 응답 지연일 수 있습니다.

### 저장소가 비어 있거나 로그인 안내가 표시됩니다.

- 저장소는 로그인 후 사용할 수 있습니다.
- 로그인 직후에는 **저장소** 탭을 다시 선택합니다.
- 원격 단어 API를 사용할 수 없으면 저장 단어가 브라우저 임시 저장으로 표시될 수 있습니다.
- 브라우저 또는 확장 프로그램 저장공간을 초기화하면 로컬 기록이 삭제될 수 있습니다.

### 개발자 모드에서 오류가 표시됩니다.

- Chrome에 선택한 폴더가 실제 `manifest.json`이 있는 폴더인지 확인합니다.
- 배포 ZIP을 다시 압축 해제하고 폴더 안의 파일이 누락되지 않았는지 확인합니다.
- 카드의 **오류** 버튼에서 표시되는 파일명과 오류 문구를 기록합니다.
- 운영자에게 오류 문구, Chrome 버전, 확장 프로그램 버전을 함께 전달합니다.

## 9. 보안 및 개인정보 주의사항

- API 키, Supabase secret key, Google client secret, 비밀번호 또는 refresh token을 사용자 입력으로 요구하지 않습니다.
- 인증 세션은 확장 프로그램 저장소에서 관리되며, 로그아웃하면 확장 프로그램에 저장된 인증 세션이 제거됩니다.
- AI Tutor 질문에는 비밀번호, 주민등록번호, 결제정보 등 민감정보를 입력하지 않는 것을 권장합니다.
- 현재 영상 정보와 필요한 자막 문맥이 Tutor 또는 사전 기능을 위해 서버로 전송될 수 있습니다.
- 처리되는 정보와 보관·삭제 정책은 [개인정보처리방침](../privacy.html)을 확인하십시오.
