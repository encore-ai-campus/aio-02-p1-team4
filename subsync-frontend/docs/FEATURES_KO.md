# SubSync 기능 설명서

이 문서는 SubSync의 기능을 사용자 안내, 기획 문서 및 Chrome Web Store 설명에 활용할 수 있도록 정리한 문서입니다.

## 1. 제품 한 줄 설명

> YouTube 영상을 보며 영·한 이중자막, 단어 즉시 학습, 전체 스크립트 및 AI Video Tutor를 사용할 수 있는 Chrome 확장 프로그램입니다.

## 3. 핵심 기능 상세

### 3.1 SubSync 퀵바

YouTube 영상 위에 고정되는 작은 컨트롤 바입니다.

- `SubSync · ON/OFF`: 주요 학습 UI를 켜거나 끕니다.
- `스크립트`: 전체 Script를 열거나 닫습니다.
- 펼침/접힘 버튼: 메인 패널을 표시하거나 숨깁니다.
- 드래그 영역: 퀵바 위치를 옮깁니다.

퀵바와 메인 패널은 YouTube 기본 레이아웃 위에 겹쳐 표시되며, 패널을 닫아도 확장 프로그램은 설치 상태로 유지됩니다.

### 3.2 영·한 이중자막

SubSync는 현재 영상의 자막 정보를 읽어 표준 자막 문장으로 변환합니다. 영상 재생 위치에 맞춰 현재 문장을 영상 위와 메인 패널에 표시합니다.

- 영어 학습 문장과 한국어 문장을 함께 표시합니다.
- 현재 자막 문장은 재생 위치에 맞춰 갱신됩니다.
- 한국어 자막이 없는 경우 영어만 표시되거나 경고 상태가 표시될 수 있습니다.
- 자막 요청 실패, 빈 응답, 파싱 실패 및 요청 제한을 서로 다른 오류 상태로 안내합니다.
- 사용자가 별도의 자막 인증값을 입력하는 흐름은 제공하지 않습니다.

### 3.3 Hover 단어 학습

영어 문장의 단어는 개별 토큰으로 표시됩니다. 단어에 마우스를 올리면 사전 API를 통해 간단한 뜻을 조회하고 툴팁으로 표시합니다.

툴팁 구성:

- 단어
- 간단한 뜻
- 저장 별표
- `클릭하여 자세히 보기` 동작

툴팁은 화면 위·아래 공간을 계산하여 대상 단어를 가리지 않는 위치에 표시됩니다. 사전 응답은 세션 동안 캐시될 수 있습니다.

### 3.4 상세 단어 학습 및 저장

단어를 클릭하면 로그인 상태를 확인한 후 상세 팝업을 표시합니다.

상세 팝업에서 제공하는 정보:

- 단어와 발음기호
- 품사
- 대표 의미
- 정의 목록
- 현재 문맥의 의미
- 관련 표현
- 저장하기/저장 취소

저장 시 영상 ID, 현재 시점, 문맥 문장이 함께 저장될 수 있습니다. 서버 저장이 실패하는 경우 브라우저 로컬 학습 기록으로 임시 저장할 수 있습니다.

### 3.5 전체 Script

Script는 현재 영상의 전체 자막을 시간순으로 표시하는 패널입니다.

- 시작 시각을 선택하면 해당 시점으로 이동하고 재생합니다.
- 현재 재생 중인 문장을 자동으로 강조합니다.
- 재생 중에는 현재 위치를 따라 자동 스크롤할 수 있습니다.
- 검색 버튼을 눌러 영어 단어 또는 문장을 필터링합니다.
- 목록을 접거나 다시 펼칠 수 있습니다.
- Script 패널을 닫았다가 퀵바에서 다시 열 수 있습니다.

### 3.6 AI Tutor

AI Tutor는 현재 영상의 학습 문맥을 활용하는 대화형 기능입니다.

질문 요청에 포함될 수 있는 정보:

- 현재 영상 ID
- 현재 재생 시점
- 최근 자막 문장
- 대화 이력
- 사용자가 직접 입력한 질문

주요 기능:

1. 사용자가 영상 표현이나 내용을 질문합니다.
2. 백엔드가 Tutor provider를 통해 답변을 생성합니다.
3. 대화 ID를 사용하여 최근 대화 흐름을 유지합니다.
4. Tutor 선제 질문이 켜져 있으면 유용한 표현에 대해 질문을 표시합니다.
5. 답변에 대해 도움됨/아쉬움 피드백을 전송합니다.

운영 백엔드는 Gemini, Groq 또는 개발용 stub provider를 사용할 수 있습니다. provider 설정과 사용량 제한에 따라 답변 시간과 품질이 달라질 수 있습니다.

### 3.7 저장소: 단어

저장소의 단어 탭은 저장된 단어를 최신순으로 보여줍니다.

- 단어
- 뜻
- 문맥 문장
- 저장 개수
- 삭제 버튼

원격 단어 목록이 제공되면 원격 목록을 우선 사용하고, 원격 응답이 없으면 브라우저의 로컬 저장 목록을 사용할 수 있습니다. 이 동작은 로그인 상태와 운영 API 구성에 영향을 받습니다.

### 3.8 저장소: 시청기록

시청기록은 `chrome.storage.local` 기반의 브라우저 학습 기록입니다.

- 영상 ID
- 영상 제목
- 썸네일
- 누적 시청 시간
- 마지막 시청 시각

영상이 재생 중일 때 일정 시간 간격으로 시청 시간이 기록됩니다. 일시정지 또는 종료 상태에서는 시간을 누적하지 않습니다. 영상 카드의 제목이나 썸네일을 선택하면 YouTube 영상 링크를 새 탭에서 엽니다.

### 3.9 Google 로그인

Google 로그인은 Chrome Identity API와 Supabase Auth PKCE 흐름을 사용하도록 구성되어 있습니다.

- 로그인 모달에서 Google 로그인 버튼을 사용합니다.
- 세션은 확장 프로그램 저장소에 보관됩니다.
- 만료된 세션은 refresh token을 사용하여 갱신하도록 구성되어 있습니다.
- 로그아웃하면 저장된 인증 세션을 제거합니다.

공개 배포 전 Supabase URL, publishable/anon key, Google provider 설정, callback URL 및 확장 프로그램 ID를 반드시 대조해야 합니다.

### 3.10 설정

| 설정 | 설명 |
| --- | --- |
| 영·한 이중자막 | 영어·한국어 자막 동시 표시 여부 |
| Hover 단어 학습 | 단어 Hover 시 빠른 뜻 표시 여부 |
| Tutor 선제 질문 | Tutor가 먼저 학습 질문을 표시할지 여부 |
| 단어 저장 방식 | 자동 저장 또는 저장 버튼 사용 방식 |
| 화면 테마 | 다크·화이트·글라스 테마 |
| 폰트 | 기본 시스템 폰트 또는 GMarketSans |

설정은 `chrome.storage.local`에 저장되며 다음 영상이나 페이지를 열 때도 유지됩니다.

### 3.11 이동·복귀·새로고침

- 퀵바 드래그: 퀵바 위치 이동
- 메인 패널 헤더 드래그: 패널 위치 이동
- 영상 자막 드래그: 영상 위 자막 위치 이동
- 더블클릭: 기본 위치 복귀
- 새로고침 버튼: 현재 영상 자막 재빌드
- 화면 크기 변경: 패널·자막 위치를 화면 안쪽으로 재조정

## 4. 데이터 및 보안

### 처리될 수 있는 정보

- Google 로그인 이메일 및 인증 세션 정보
- 현재 YouTube 영상의 제목, URL, 영상 ID
- 현재 영상의 자막 및 텍스트 콘텐츠
- AI Tutor 질문, 대화 문맥 및 피드백
- 저장 단어, 문맥 문장, 시청기록
- 사용자가 선택한 설정값

### 보호 원칙

- 비밀 API 키와 Google client secret은 서버 또는 Supabase Dashboard에만 보관합니다.
- 확장 프로그램에는 공개용 Supabase URL 및 publishable/anon key만 포함할 수 있습니다.
- `service_role` 키, JWT secret, refresh token을 코드·문서·로그에 노출하지 않습니다.
- 자막과 Tutor 사용자 입력은 신뢰할 수 없는 텍스트로 취급하고 HTML로 직접 실행하지 않습니다.
- 상세한 처리 목적과 제3자 AI 서비스 사용 여부는 [개인정보처리방침](../privacy.html)에 따릅니다.

## 5. 현재 배포 시 확인해야 하는 제한사항

### 운영 API 주소

프론트엔드의 현재 기본 API 주소는 `http://127.0.0.1:8000/api/v1`입니다. 공개 배포 전 HTTPS 운영 백엔드 주소로 변경하고, Manifest 호스트 권한과 CORS를 함께 갱신해야 합니다.

### 프론트 호출 API와 백엔드 등록 API

프론트엔드는 다음 계열의 API를 사용합니다.

- `/tutor/ask`
- `/tutor/proactive`
- `/tutor/feedback`
- `/dictionary/hover`
- `/dictionary/detail`
- `/words/list`
- `/words/save`
- `/words/{id}`
- `/logs/event`

현재 백엔드 코드에서 확인된 Tutor 라우터는 `/tutor/ask`, `/tutor/proactive`, `/tutor/feedback`, `/tutor/usage`입니다. 사전·단어·이벤트 로그 API는 공개 배포 전에 실제 라우터와 인증·소유권 검사를 추가하거나, 프론트의 fallback 및 기능 노출 정책을 별도로 정해야 합니다.

### 저장 방식 설정

설정 화면에는 자동 저장/수동 저장 선택지가 있습니다. 저장 방식별 사용자 경험이 배포 코드에서 의도대로 동작하는지 출시 전 수동 QA로 확인해야 합니다.

### 자막 제공 여부

YouTube 영상별 자막 트랙, 언어, 요청 제한 및 플레이어 상태에 따라 자막 표시 결과가 달라질 수 있습니다.

### 짧은 설명

YouTube 영·한 이중자막과 AI Tutor로 영상을 보며 자연스럽게 영어를 학습하세요.

### 주요 기능

- 영어·한국어 이중자막

- 클릭 한 번으로 단어 저장
- 타임스탬프 기반 전체 Script
- 영상 문맥 기반 AI Video Tutor
- 단어장과 시청기록
- 다크·화이트·글라스 테마
- 시스템 폰트·GMarketSans 선택
